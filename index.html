下載與事前準備

  • Blender 官方下載免費開源，建議使用最新穩定版（至少 4.3.2 以上）
  • Blosm for Blender（Gumroad）價格欄可填 0 免費下載 zip 檔
  • Google Map Tiles API在 Google Cloud Console 啟用並建立金鑰
  • Rhino 下載官方下載頁，另有 90 天試用版
  • Blosm 官方說明：3D Tiles參數說明與材質匯出的官方文件

開始前請先確認
  • 一張可綁定 Google Cloud 計費帳戶的信用卡（有免費額度，但申請金鑰時必須綁卡）。
  • 穩定的網路，且未被公司防火牆或 VPN 擋住 tile.googleapis.com。
  • 足夠的硬碟空間與記憶體：大範圍、高精度的地形動輒數百萬面。
1

下載與安裝 Blender

Blender

基礎環境準備。

  1. 前往 blender.org 下載最新穩定版安裝檔，一路點「下一步」完成安裝。
  2. 開啟 Blender，在啟動畫面選擇 General（一般） 建立新專案。
  3. 滑鼠移到 3D 視窗，按 A 全選預設的方塊、燈光與攝影機，再按 Delete 刪除，保持場景乾淨。
2

下載與安裝 Blosm 外掛

Blender

地圖圖資神器。

  1. 前往 Gumroad 的 Blosm 頁面，下載 zip 壓縮檔（免費版即可，不要解壓縮）。
  2. 回到 Blender，點選 編輯 Edit › 偏好設定 Preferences › 附加元件 Add-ons。
  3. 點右上角 安裝 Install 並選取 zip 檔。
    Blender 4.2 以後的版本：按右上角的 ▾ 下拉選單，選 從磁碟安裝 Install from Disk。
  4. 勾選 Blosm 前面的核取方塊啟用外掛。
  5. 先在電腦建立一個存放圖資快取的資料夾，例如 D:\Blosm_data（路徑盡量避免中文與空格）。
  6. 展開 Blosm 設定，在 Directory 選取該資料夾。
  7. 點左下角 ☰ › Save Preferences 儲存設定，否則重開 Blender 後會消失。
  8. 回到 3D 視窗按 N，右側出現 Blosm 分頁即代表安裝成功。

沒設定資料夾會怎樣？按 import 時會跳出 The directory for data in the addon preferences doesn't exist 錯誤，無法匯入。

3

綁定 Google 3D Tiles API

Google Cloud

獲取實景數據權限。

  1. 在 Blosm 面板將資料來源下拉選單切換為 3D Tiles，來源選 Google。
  2. 點面板上的 Get API Key（或直接前往 Google Cloud Console）。
  3. 建立專案並設定計費帳戶，接著到 API 程式庫啟用 Map Tiles API。
  4. 在 API 和服務 › 憑證 建立 API 金鑰並複製。
  5. 把金鑰貼回 Blosm 的 API Key 欄位（部分版本位於外掛偏好設定中）。

安全提醒：建議在 Google Cloud 將金鑰限制為只能呼叫 Map Tiles API，並設定每日用量上限，避免金鑰外流產生費用。

4

匯入地圖與修正視角裁切

Blender

解決畫面邊緣消失的問題。

  1. 在 Blosm 面板按 select 開啟地圖，框選目標範圍後貼回座標（Extent）。
  2. 在 Settings 將 Source 設為 Google，Level of details 依需求選擇（例如 buildings with details；選項名稱依 Blosm 版本不同，舊版可能叫 ultimate）。
  3. 建議勾選 Join 3D Tiles objects，讓所有圖塊合併成單一物件。
  4. 點 import 匯入，等待下載與組合。
  5. 若轉動視角時邊緣消失：在右側側邊欄（N）切到 檢視 View 分頁，修改 剪裁 Clipping：
欄位設定值
Clip Start0.1 m
End50000 m

先小後大：第一次請從約 1×1 km 的範圍開始測試。範圍太大或精度太高，下載時間與面數都會暴增。

5

固化網格與提取材質

Blender

鎖定高精度細節。

  1. 確認 3D 視窗處於高精度顯示狀態，點選地圖模型。
  2. 到右側 修改器（藍色扳手） 面板，找到 GeometryNodes 修改器，選 套用 Apply（快捷鍵 Ctrl+A）固化網格。
  3. 將頂部工作區切換到 Shading 分頁。
  4. 在下方節點視窗找到橘色的 Image Texture 節點。
  5. 在上方圖片編輯器開啟該圖，使用 Image › Save As 另存到桌面，命名為 base_map.jpg。

⚠先確認貼圖有幾張

Google 3D Tiles 由許多圖塊組成，每個圖塊各有一張衛星照片。即使勾選 Join，合併後的物件仍保有多個材質（常見數十到上百個）。

在 材質屬性（紅色球圖示） 查看材質槽數量：

・只有 1 個材質：照本步驟另存 base_map.jpg，接步驟 6～8 即可。
・多個材質：只存一張圖的話，Rhino 只會有一小塊有顏色、其餘全灰。請改走下方 Python 修復材質＋FBX 內嵌貼圖 流程。

多張貼圖的情況：若圖塊沒有合併，可能出現許多張各自獨立的貼圖。Blosm 的材質無法直接匯出，官方說明提供把材質轉為可匯出版本的功能；Pro 版另有一鍵烘焙成單張貼圖的功能，詳見官方文件。也可以改用下方的 Python 修復材質＋FBX 內嵌貼圖 流程，一次處理所有貼圖。

6

執行匯出設定

Blender

轉存為通用格式。

  1. 選取地圖模型，點 檔案 File › 匯出 Export › Wavefront (.obj) 或 FBX。
  2. 在右側匯出設定面板中調整以下項目後，點 匯出。
設定項目設定值
屬性／評估模式（Properties / Evaluation Mode）算圖 Render（不要用視圖區 Viewport）
僅限選取的物件（Selected Only）勾選
套用變換（Apply Transform）勾選
UV 座標（UV Coordinates）勾選（OBJ 預設開啟）
Materials › Export（多貼圖時）勾選
Materials › Path Mode（多貼圖時）Copy

OBJ 多貼圖注意：匯出後的 .obj、.mtl 與所有貼圖必須放在同一個資料夾，Rhino 才讀得到。多貼圖情況更推薦用 FBX 內嵌貼圖。

⚠極遠座標當機警告（Far from Origin）

GIS 圖資帶有真實地球座標，匯入 Rhino 時距離原點極遠，會引發嚴重的浮點運算誤差：畫面瘋狂閃爍、破面，甚至無法正常旋轉。

匯入 Rhino 後的第一件事：使用 Move 指令選取整塊基地，將其強制移動到絕對座標 0,0,0，再進行後續步驟。

7

Rhino 匯入與網格修復

Rhino

解決破面與黑影。

  1. 匯入前先確認 Rhino 右下角的單位。Blender 預設為公尺，若 Rhino 檔是公分，比例可能差 100 倍，建議使用公尺樣板，或匯入時留意單位換算提示。
  2. 在 Rhino 使用 檔案 › 匯入（或 Import）匯入剛才的模型。
  3. 先處理座標：選取整塊基地，執行 Move 移至 0,0,0。
  4. 選取網格，在指令欄輸入 ClearAllMeshes，清除錯誤的顯示快取。
  5. 輸入 Weld，將角度設為 180，把分離的頂點黏合平滑。
  6. 確認原本黑白不均的陰影變得平滑乾淨。
  7. 用 Distance 量一條已知寬度的道路或建築，確認比例正確。
8

貼回材質實景色彩

Rhino

完美對位。

  1. 將 Rhino 視窗切換至 彩現模式 Rendered。
  2. 開啟存放 base_map.jpg 的資料夾，把圖片直接拖曳進 3D 視窗，放在地圖模型上。
  3. 在彈出選項中選擇 材質 Material。
  4. 對應方式選擇 使用現有的 UV 座標 Use Existing UV Channels。

完成判斷：實景色彩準確貼合地形與建築，就大功告成了。

只有一小塊有顏色、其他全灰？代表模型有多張貼圖，這一步只補上了其中一張。指令列若顯示 xxx meshes added to selection，數字大約就是貼圖數量。請改用 FBX 內嵌貼圖流程。

進階：用 Python 修復材質並匯出 FBX

要走哪條路，取決於你現在的工作階段與目的。先選路徑：

路徑一｜Blender 基地 → Rhino 設計

當作設計底圖

需要 Google 實景模型在 Rhino 裡當背景，做建築量體推敲或出圖。本段的 Python 腳本就是為這條路徑準備的。

路徑二｜Rhino 設計 → Blender 渲染

做影片或效果圖

如果目的是渲染，把 Rhino 模型匯進 Blender 通常更快、效果也更好，實景地形不必離開 Blender。

路徑一：一鍵修復 Blosm 材質

Blosm 抓下來的模型常用 Emission（發光）節點顯示貼圖，這會讓 FBX 匯出後沒有貼圖。下方腳本會把所有選取物件的材質改接到標準的 Principled BSDF，匯出 FBX 給 Rhino 時就會帶著貼圖。

  1. 完成步驟 4、5 的匯入與「套用 GeometryNodes 修改器」。
  2. 頂部工作區切到 Scripting 分頁，點 ＋ New 建立新文字檔。
  3. 貼上下方程式碼。
  4. 回到 3D 視窗選取所有地圖模型，再回到 Scripting 按 ▶ Run Script（或 Alt+P）。
  5. 到 Window › Toggle System Console 查看「材質修復完成」訊息（Windows）。

版本相容：Blender 4.0 起 Principled BSDF 的「Specular」改名為「Specular IOR Level」，腳本會自動判斷，新舊版本都能執行。

路徑一：匯出 FBX 並帶入 Rhino

  1. 保持地圖模型選取狀態，點 File › Export › FBX (.fbx)。
  2. 依下表設定後按 Export FBX。
設定項目設定值
Limit to › Selected Objects勾選
Path ModeCopy
Embed Textures（Path Mode 右側的小方塊圖示）按下開啟
Geometry › Apply Modifiers勾選
  1. 在 Rhino 執行 Import 匯入 FBX。
  2. 先依極遠座標警告用 Move 移到 0,0,0，再做步驟 7 的網格修復。
  3. 切到 彩現模式 Rendered，即可看到內嵌的貼圖，不必再手動拖曳 base_map.jpg。

路徑二：Rhino 模型匯進 Blender 渲染

  1. 在 Rhino 把設計量體移到與基地一致的參考點，單位設為公尺。
  2. 匯出成 FBX 或 OBJ；或在 Blender 安裝 import_3dm 外掛，直接讀取 .3dm。
  3. 在已有 Blosm 地形的 Blender 場景中匯入模型，對齊位置後即可設定燈光與攝影機進行渲染。

常見問題排除

匯入時出現 HTTP Error 400 或無法處理 root URI

先確認 Google Cloud 已啟用 Map Tiles API、計費帳戶有效、金鑰沒有被 IP 或 API 限制擋住。仍失敗時檢查防火牆、Proxy 或 VPN；有使用者回報 BlenderKit 外掛會阻擋 Blosm 的連線，可暫時停用測試。

按 import 出現「The directory for data in the addon preferences doesn't exist」

Blosm 的快取資料夾沒設定，或資料夾已被刪除、搬移。建立一個資料夾（如 D:\Blosm_data），到 Edit › Preferences › Add-ons › Blosm 的 Directory 選取它，再點左下角 ☰ › Save Preferences。之前失敗留下的空白「Google 3D Tiles.00x」集合可在 Outliner 中刪除。

出現 KHR_draco_mesh_compression 相關錯誤

通常是 Blender 版本太舊，請更新到最新穩定版後重新匯入。

Blosm 面板裡找不到 3D Tiles 選項

確認外掛是最新版，並在偏好設定中已指定 Directory 資料夾與填入金鑰；更新後重新啟動 Blender。

轉動視角時地形邊緣一直消失

回到步驟 4，把 View 分頁的 Clip Start 設 0.1 m、End 設 50000 m。

匯出後的模型很粗糙，和 Blender 裡看到的不一樣

匯出時的屬性仍是「視圖區 Viewport」。請改為「算圖 Render」，並確認步驟 5 已套用 GeometryNodes 修改器。

Rhino 中畫面閃爍、破面、無法旋轉

這是極遠座標造成的浮點誤差。用 Move 把整塊基地移到 0,0,0。

Rhino 模型表面黑白斑駁

頂點法線不一致。依序執行 ClearAllMeshes 與 Weld（角度 180）。

Rhino 裡只有一小塊有實景顏色，其他全是灰色

Google 3D Tiles 每個圖塊各有一張貼圖，合併後仍是多材質（Rhino 匯入時會拆成數十到上百個 mesh）。步驟 5 只另存了其中一張，所以只有對應的那塊有顏色。解法由快到正規：① 跑 Python 修復腳本後匯出 FBX（Path Mode: Copy＋Embed Textures）；② OBJ 勾選 Materials Export、Path Mode: Copy，並把 .obj/.mtl/貼圖放同一資料夾；③ 在 Blender 烘焙成單張貼圖（Blosm Pro 內建，免費版需手動設定 Bake）。

匯入 Rhino 後比例怪怪的（太大或太小）

Blender 預設單位是公尺，Rhino 檔若設為公分會差 100 倍。確認 Rhino 右下角的單位，並用 Distance 量已知尺寸驗證；必要時以 Scale 依原點縮放 100 倍或 0.01 倍。

貼圖位置錯亂或整片拉伸

拖曳圖片時要選「使用現有的 UV 座標」。若仍錯亂，回到 Blender 確認匯出時有勾選 UV 座標，並檢查是否有多張貼圖（見步驟 5 的說明）。

圖資可以用在正式提案或對外發表嗎？

Google 3D Tiles 受 Google Maps Platform 服務條款約束，包含標示來源與限制快取、再散布等規定。對外使用前請先閱讀條款或與公司內部確認。
